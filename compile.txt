To compile PtokaX on Unix operating system is needed to have installed: GNU make, GCC or Clang compiler, Lua, zlib.
Optionaly for database support is required: PostgreSQL or SQLite or MySQL or MariaDB.
On most Unixes are these things available as packages.
	
Compile guides for different Operating Systems are available in PtokaX Wiki http://wiki.ptokax.org/doku.php?id=guides.


Short compile instruction:

Compile on Debian/Mint/Ubuntu/Dyson:
Packages to install: make g++ zlib1g-dev and liblua5.4-dev or liblua5.2-dev or liblua5.1-dev for required Lua version.
Optional package for PostgreSQL database support: libpq-dev
Optional package for MariaDB database support: libmariadb-client-lgpl-dev-compat
Optional package for MySQL database support: libmysqlclient-dev
Optional package for SQLite database support: libsqlite3-dev
To compile PtokaX with without database: ./configure --with-lua=5.4 && make for Lua 5.4 or ./configure --with-lua=5.2 && make for Lua 5.2 or ./configure --with-lua=5.1 && make for Lua 5.1
To compile PtokaX with PostgreSQL database: ./configure --with-database=postgres --with-lua=5.4 && make for Lua 5.4 or ./configure --with-database=postgres --with-lua=5.2 && make for Lua 5.2 or ./configure --with-database=postgres --with-lua=5.1 && make for Lua 5.1
To compile PtokaX with MariaDB or MySQL database: ./configure --with-database=mysql --with-lua=5.4 && make for Lua 5.4 or ./configure --with-database=mysql --with-lua=5.2 && make for Lua 5.2 or ./configure --with-database=mysql --with-lua=5.1 && make for Lua 5.1
To compile PtokaX with SQLite database: ./configure --with-database=sqlite --with-lua=5.4 && make for Lua 5.4 or ./configure --with-database=sqlite --with-lua=5.2 && make for Lua 5.2 or ./configure --with-database=sqlite --with-lua=5.1 && make for Lua 5.1
